## Engineering Principles

- **Understand before implementing.**
- **Prefer first-principles reasoning over framework memorization.**
- **Use primary sources whenever possible.**
- **Measure performance instead of assuming it.**
- **Document failures, not only successful results.**
- **Keep experiments reproducible.**
- **Separate research claims from engineering claims.**
- **Build artifacts that can be inspected, tested, and reproduced.**
